# porterjenkins.com

Personal website, hosted on GitHub Pages from the `main` branch.

- `index.html` — the site
- `CNAME` — custom domain (`porterjenkins.com`)
- `.nojekyll` — serve files as-is, no Jekyll processing

## Local preview

```sh
python3 -m http.server 8000
```

Then open http://localhost:8000.
